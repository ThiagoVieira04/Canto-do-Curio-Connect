# Canto do Curió Rações

Landing page para pet shop com rações, medicamentos e acessórios para pets.

## Funcionalidades

- **WhatsApp** - Link direto para atendimento
- **Avaliação Google** - Redirecionamento para página de avaliação
- **Instagram / Facebook** - Links para redes sociais
- **Localização** - Google Maps
- **Pix** - Chave pix para pagamento com cópia
- **WiFi** - Dados da rede com botão copiar senha
- **QR Code** - Compartilhamento da página

## Tecnologias

- HTML5
- CSS3 (responsivo, dark mode)
- JavaScript vanilla
- Font Awesome (ícones)
- QRCode.js

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Para hospedar, faça deploy no Vercel, Netlify ou GitHub Pages

## Estrutura

```
├── index.html      # Página principal
├── style.css       # Estilos e responsividade
├── script.js       # Funcionalidades
├── logo.png        # Logo do pet shop
├── logo-google.png # Ícone do Google
├── pix.png         # QR Code Pix
├── local.gif       # Ícone de localização
└── vercel.json     # Configuração de deploy
```
